# A3 Jira Mapping

Use one shared Jira project for the team. Suggested epics: **Member Weekly Ordering** and **Coordinator & Packing Operations**.

Suggested stories: login; view products; place order; edit/cancel order; unit/kg pricing; product maintenance; member maintenance; weekly round creation; historical price snapshot; all-orders view; product totals; packing sheet; record packed quantity; audit trail; round report/CSV export.

Branch convention: `feature/GHC-<issue>-short-name`. Every story should contain user story wording, acceptance criteria, story points, assignee, sprint, evidence and a linked Pull Request.
