# Project Charter

**Project:** Greenhill Food Co-op Ordering System  
**Purpose:** Replace paper order re-entry with a reliable weekly ordering workflow while preserving the co-op's existing pickup process.

## Objectives
- Members enter their own weekly orders.
- Coordinator manages products, members and rounds.
- Pricing correctly distinguishes per-unit and per-kilogram goods.
- Packing records actual quantities and short supply.
- The code is reproducible from GitHub using README instructions.

## Team governance
Three team members rotate the project-manager role. Record the rotation, responsibilities, decisions and approvals in Jira/Confluence.
