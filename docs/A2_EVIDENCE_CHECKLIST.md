# A2 evidence checklist

Capture your own screenshots while you work; do not fabricate history after development.

- GitHub repository overview
- meaningful commit history
- feature branches
- a Pull Request and review/merge
- `.gitignore`, `.env.example`, dependency file and Docker/config files
- passing automated tests / GitHub Actions
- running member product catalogue
- member order page showing unit and kg items
- coordinator product/round management
- round total view
- tagged release if used

The A2 configuration-management report should explain what you actually did, not merely reproduce this checklist.
